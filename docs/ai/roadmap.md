# Roadmap перехода AI-функций на Yandex AI Studio

Архитектура и карта кода: [architecture.md](architecture.md). План: [migration-plan.md](migration-plan.md). Исходное состояние: [current.md](current.md).

Последнее обновление: 11 ноября 2026 года.

## Правила ведения

Этот файл — реестр прогресса переноса и временных отключений. Обновлять его в той же поставке, которая меняет маршрут или доступность функции.

Согласовано с пользователем: допускается временно отключать неподдерживаемые функции. Для каждого отключения обязательно фиксировать причину и условия включения. Неразрешённый внешний провайдер не используется как замена отключённой функции.

Статус переноса и доступность учитываются отдельно:

- Перенос: `не начат`, `в работе`, `реализован, не проверен`, `проверен на тестовом окружении`, `включён в production`.
- Доступность в целевом региональном окружении: `не настроена`, `включена`, `выключена`.
- Планируемое отключение не считается выполненным. После фактического изменения указать окружение, дату, причину и ссылку на изменение / проверку.
- Перед переключением окружения у каждой функции должен быть проверенный разрешённый маршрут либо зафиксированное отключение. Для отключённой функции должны быть определены поведение UI/API и условие восстановления.

Этапы 1 и 2 реализованы. Пользователь подтвердил четыре успешные CLI-пробы Yandex и работу чата локально и на стенде. Остальные бизнес-сценарии этапа 2 отдельно не подтверждены; production не проверен. Код этапа 3 реализован: прямые изображения/PDF/аудио, серверный микрофон и Yandex Search API управляются одним профилем. Видео и неподдерживаемые аудиоконтейнеры временно отключены после удаления локальной предобработки. Реальная приёмка отложена до стенда по просьбе пользователя. Неподдержанные возможности явно отключены ниже. Инструкции: [stage-2-check.md](stage-2-check.md), [stage-3-check.md](stage-3-check.md).

## Этапы

| Этап | Содержание | Статус | Условие завершения |
| --- | --- | --- | --- |
| 1 | Серверная конфигурация, политика, resolver и явный адаптер старого Gateway | Реализован, проверен локально | В новом runtime подключения управляются конфигурацией; запрещённый маршрут отвергается сервером. Перевод существующих вызовов — следующий этап |
| 2 | Прямой адаптер Yandex и текстовые сценарии | Чат проверен локально и на стенде; остальные сценарии требуют проверки | Пользователь подтвердил четыре CLI-пробы и чат; остальные бизнес-сценарии принимать отдельно |
| 3 | PDF, изображения, аудио, видео, веб-поиск и голосовой ввод | Реализован, не проверен на стенде; временные ограничения оформлены | Для каждой функции проверен маршрут либо оформлено временное отключение |
| 4 | Проверка регионального окружения и переключение | Не начат | Заполнен реестр функций и отключений; выполнены проверки маршрутов из плана |

Первый этап переноса функций — текстовые сценарии. Остальные проверяются отдельно; их временное отключение допустимо с записью в этом реестре. Готовность к переключению оценивается по фактическим статусам, а не только по завершению разработки.

## Ограничения, реализованные в Yandex-профиле

Ограничения ниже реализованы в `config/ai/yandex.json` и серверных проверках. Пользователь подтвердил работу чата на стенде; полный аудит запретов там ещё не проводился. Новые функции включаются в том же JSON либо его сгенерированной копии для ConfigMap. Дополнительный `yandex-media.json` удалён.

| Функция / маршрут | Поведение профиля | Причина | Условие включения / замены |
| --- | --- | --- | --- |
| Vercel Gateway и текущие внешние модели | Запрещены в региональном профиле; адаптеры сохранены | Не являются утверждённым региональным маршрутом | В этом профиле не включать без изменения утверждённых требований |
| Google Search | Выключена | Внешний маршрут вне утверждённой инфраструктуры | Проверенная замена на разрешённый поиск |
| Браузерный SpeechRecognition | Выключен | Сервис обработки определяется браузером, регион не контролируется приложением | Проверенная серверная интеграция разрешённого STT |
| Произвольное чтение сайтов | Выключено | Адреса, редиректы и обработка запросов могут находиться за пределами региона | Согласованный и технически ограниченный способ получения публичных данных |
| Непроверенные PDF / изображения / аудио / видео | Все эти задачи выключены; вызовы проверяются resolver | Совместимость и региональный маршрут ещё не подтверждены | Успешная проверка формата, качества, ограничений, хранения и маршрута |
| Определение говорящих | Выключено; текст и таймкоды сохраняются из STT, метки `Unknown` | Надёжная diarization не реализована | Проверить выделение говорящих и сохранить результат без домыслов LLM |
| Видео | Выключено; выборка кадров удалена | Нет подтверждённого прямого API Yandex, локальные зависимости удалены | Разрешённая интеграция видео и приёмка |
| M4A / WebM / FLAC / OGG Vorbis в Yandex | Явно отклоняются; микрофон формирует WAV | Нет прямой поддержки в подключённом SpeechKit API, конвертация удалена | Отдельная разрешённая поддержка форматов |
| Вложения в Yandex-чате | Выключены в UI и отклоняются сервером, включая историю сообщений | Чат пока не подключён к предобработке файлов Sources | Отдельная проверенная обработка вложений и истории чата |
