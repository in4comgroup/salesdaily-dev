# Эксплуатация: вход и ИИ

Переменные окружения, деплой, проверки после деплоя и частые проблемы для функций из этой документации. Общий порядок деплоя и кластера: [deploy/k8s/README.md](../../deploy/k8s/README.md), миграции: [docs/deploy/database-migrations.md](../deploy/database-migrations.md).

## Переменные окружения

На кластере — Secret `crm-env` (список ключей: [env.example](../../deploy/k8s/app/env.example)). Значения не коммитятся и не печатаются. Переменную лучше не задавать совсем, чем задать пустой.

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL` | Да | Сессии и адрес сайта для better-auth |
| `EMAIL_PROVIDER` + `NYLAS_*` / `RESEND_*` | Да | Отправка писем с кодом входа и приглашений |
| `YANDEX_AI_API_KEY`, `YANDEX_AI_FOLDER_ID` | Если включена хотя бы одна модель или сервис | Доступ к Yandex AI Studio; каталог моделей и сервисов |
| `YANDEX_AI_API_URL` | Нет | Адрес AI Studio (https, без пути). По умолчанию `https://ai.api.cloud.yandex.net` |
| `YANDEX_OCR_API_KEY` | Если включён OCR | Vision OCR (PDF) |
| `YANDEX_SPEECH_API_KEY` | Если включён SpeechKit | Аудио и голосовой ввод |
| `YANDEX_SEARCH_API_KEY` | Если включён Search API | Веб-поиск, данные компаний |
| `YANDEX_BILLING_SA_KEY`, `YANDEX_BILLING_ACCOUNT_ID` | Нет (обе вместе) | Автоматические цены моделей |
| `DATABASE_URL`, `DATABASE_POOL_MAX` | Да / нет | БД; размер пула на процесс |

Больше **не читаются** и могут быть удалены из `crm-env` и `.env`: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `AI_GATEWAY_API_KEY`, `YANDEX_AI_TEXT_MODEL_URI`, `YANDEX_AI_VISION_MODEL_URI`, `AI_CONFIG_PATH`.

Изменение Secret требует перезапуска: `kubectl -n salesdaily rollout restart deployment/crm`.

## Деплой

- Образ и деплой — GitHub Actions (`docker-image.yml`, `deploy.yml`). Job миграций применяет новые файлы из `db/migrations/manifest.json` до обновления Deployment.
- Конфигурация маршрутов ИИ живёт в БД и деплоем не меняется. ConfigMap для ИИ больше нет.
- Новый стенд (пустая таблица `ai_config_version`): ИИ выключен, пока админ не сохранит первую версию в «Маршрутах ИИ» или оператор не загрузит её скриптом `seed` ([ai-configuration.md](ai-configuration.md#командная-строка)).

## Проверка после деплоя

1. **Вход**: `/sign-in` → свой email → код из письма → вход. Неизвестный email: экран кода появляется, письма нет.
2. **ИИ**: «Настройки → Модели → Маршруты ИИ» — «Сейчас этот сервер работает: версия N из БД», ошибок загрузки нет, все нужные ключи «✓».
3. Каталог моделей: `GET https://<стенд>/api/ai/config` — включённые процессы.
4. Короткий вопрос в ИИ-чате; при включённых сервисах — разбор PDF и веб-поиск.
5. «Использование» за сегодня: вызовы появились, у моделей есть цена (нет «нет цены»).
6. «Цены Yandex»: последняя проверка «успешно» (если Billing API настроен).

## Частые проблемы

| Признак | Причина | Что делать |
| --- | --- | --- |
| Письмо с кодом не приходит | Нет аккаунта (экран «Вход» не отправляет код незнакомым адресам); спам; ошибка почтового провайдера | Проверить «Спам»; зарегистрироваться через `/sign-up`; в логах сервера — ошибки `[nylas]` / `[resend]` |
| «Слишком много запросов» | Лимит 3 запроса кода в минуту с адреса | Подождать минуту |
| ИИ недоступен везде («ИИ недоступен» в чате) | Нет активной версии конфигурации, версия неверна или нет ключа | «Маршруты ИИ»: строка ошибки загрузки и наличие ключей. Лог: `[ai-config] …`. Исправить env или сохранить / сделать активной рабочую версию |
| Сохранение версии отклонено | Правило конфигурации (текст в ошибке) или нет ключа / URI не из каталога | Исправить по тексту ошибки; при «Missing Yandex API key…» — добавить ключ в `crm-env` и перезапустить |
| Изменение в «Маршрутах ИИ» не действует на другом сервере | Ещё не прошла проверка (до 30 с) или у этого сервера ошибка загрузки | Подождать; проверить лог `[ai-config]` этого pod |
| Отдельный процесс отвечает ошибкой политики | Процесс выключен или модель без нужных возможностей | «Маршруты ИИ»: включить процесс, выбрать подходящую модель |
| «Дневной лимит расходов на ИИ … исчерпан» | Лимит организации на сегодня (МСК) | «Модели → Лимиты и Темы по организациям»: поднять лимит организации или общий |
| Веб-поиск / «Найти в интернете» не работают | Выключен Search API или процессы `webSearch` / `companyResearch`; нет `YANDEX_SEARCH_API_KEY` | Включить сервис и процессы, добавить ключ |
| PDF / аудио не разбираются | Выключен OCR / SpeechKit или процесс; формат не поддерживается (M4A, WebM…); лимит страниц / секунд | См. [ai-overview.md](ai-overview.md#обработка-файлов-источники) |
| «нет цены» в «Использовании» | У модели нет цены: нет связи с прайсом или Billing API не настроен | Связать модель с позицией прайса в «Цены Yandex» и «Обновить цены» или ввести цену вручную |
| Синхронизация цен: «ошибка» | Неверный ключ сервисного аккаунта, нет роли `billing.accounts.viewer`, неверный ID аккаунта | Текст ошибки в «Цены Yandex»; проверить `YANDEX_BILLING_*` |

## Логи

| Префикс | Источник |
| --- | --- |
| `[ai-config]` | Загрузка конфигурации маршрутов: какая версия работает, ошибки |
| `[llm-usage]` | Отказы по лимиту, ошибки записи учёта |
| `[llm-pricing]` | Результат синхронизации цен |
| `[web-search]` | Ошибки веб-поиска чата |
| `[chat] route:` | Модель и организация каждого запроса чата |

Логи не содержат ключей, текста запросов к моделям и ответов.
