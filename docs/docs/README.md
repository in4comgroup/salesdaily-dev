# Системная документация SalesDaily

Техническое описание функций системы: что делает функция, как она устроена, где данные, какие настройки и как её эксплуатировать. Для разработчиков, администраторов платформы и тех, кто сопровождает стенд.

Состояние на 11 ноября 2026 года.

## Разделы

| Документ | О чём |
| --- | --- |
| [auth.md](auth.md) | Вход и регистрация: только email и одноразовый код. Приглашения в организацию |
| [ai-overview.md](ai-overview.md) | ИИ-подсистема: Yandex AI Studio, процессы, модели, сервисы OCR / SpeechKit / Search, обработка файлов, веб-поиск |
| [ai-configuration.md](ai-configuration.md) | Конфигурация маршрутов ИИ в БД, блок «Маршруты ИИ», версии и откат, скрипты `seed` / `check` |
| [ai-usage-and-billing.md](ai-usage-and-billing.md) | Учёт вызовов, дневные лимиты, цены моделей, синхронизация с Yandex Billing, наценка, вкладка «Использование» |
| [operations.md](operations.md) | Эксплуатация: переменные окружения, деплой, проверки, частые проблемы |

## Правила ведения

- Документ обновляется в той же поставке, которая меняет функцию.
- Пишем, как система работает сейчас. История и причины решений — в `docs/ai/` и в git.
- Значения секретов в документацию не попадают: только имена переменных.
